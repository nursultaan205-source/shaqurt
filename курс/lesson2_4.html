Кері санақ таймері (Countdown Timer)

Тойдың басталуына қанша уақыт қалғанын секунд сайын көрсетіп тұратын динамикалық элементті сайтқа қосу.

⏳ Кері санақ таймерінің маңызы

Кері санақ таймері (Countdown Timer) — электронды шақыру сайттарына ерекше көркем атмосфера мен салтанатты сезім беретін интерактивті фишка. Ол қонақтардың мереке күнін асыға күтуіне және уақытты бақылап отыруына көмектеседі.

Мысалы, той басталғанша «15 күн, 8 сағат, 45 минут» қалғаны сан түрінде әдемі жылжып тұрса, қонақтың қызығушылығы одан сайын арта түседі.

💡 Бизнес құндылығы: Таймері бар шақыру сайттары тапсырыс берушілер арасында өте жоғары сұранысқа ие, өйткені ол сайтты «тірі» әрі динамикалық етіп көрсетеді.

💻 Таймердің HTML & CSS қаңқасы

Сайтта таймерді орналастыру үшін қарапайым блоктар жасап, оларға арнайы ID береміз:

<div class="timer-container">
  <div class="timer-box"><span id="days">00</span><p>Күн</p></div>
  <div class="timer-box"><span id="hours">00</span><p>Сағат</p></div>
  <div class="timer-box"><span id="minutes">00</span><p>Минут</p></div>
  <div class="timer-box"><span id="seconds">00</span><p>Секунд</p></div>
</div>

⚙️ JavaScript арқылы уақытты есептеу

Сандардың өздігінен азайып тұруы үшін JavaScript тілінің функциясы қолданылады. Бұл кодты сайтыңыздың соңына <script> тегінің ішіне қоясыз:

const weddingDate = new Date("Nov 15, 2026 18:00:00").getTime();

const x = setInterval(function() {
  const now = new Date().getTime();
  const distance = weddingDate - now;

  const days = Math.floor(distance / (1000 * 60 * 60 * 24));
  const hours = Math.floor((distance % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60));

  document.getElementById("days").innerText = days;
  document.getElementById("hours").innerText = hours;
}, 1000);
✨ Практик кеңесі: Әрбір клиент үшін тойдың нақты күні мен уақытын осы кодтағы `weddingDate` айнымалысына өзгертіп қоюды ұмытпаңыз!
