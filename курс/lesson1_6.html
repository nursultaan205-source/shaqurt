Сайтты интернетке қалай жүктейміз?

Localhost түсінігі, GitHub Pages арқылы тегін хостинг алу және Tilda конструкторын смартфоннан пайдалану баламасы.

⚠️ Неге компьютеріңіздегі сілтемені басқалар көре алмайды?

VS Code-та жұмыс істеп жатқанда немесе файлды екі рет басып ашқанда, браузерде file:///C:/... немесе localhost:5500 сияқты мекенжай шығады.

Бұл — локалды (ішкі) мекенжай. Бұл сілтемені клиентке немесе досыңызға WhatsApp-пен жіберсеңіз, оларда сайт АШЫЛМАЙДЫ. Себебі бұл файл тек сіздің компьютеріңіздің ішінде ғана сақтаулы тұр.

🔑 Шешім: Сайтты бүкіл әлемге және клиентке көрсету үшін оны арнайы серверге (хостингке) жүктеп, интернеттен ашылатын **онлайн сілтеме (https://...)** алу керек!

🐙 GitHub Pages арқылы сайтты жариялау

GitHub — разработчиктерге арналған ең танымал тегін платформа. GitHub Pages функциясы арқылы HTML/CSS/JS файлдарыңызды тегін сайтқа айналдыра аласыз.

Қадамдық алгоритм:

1-қадам: GitHub-та тіркелу

github.com сайтына кіріп, өзіңізге тегін аккаунт ашыңыз.

2-қадам: Жаңа репозиторий (Repository) құру

Жоғарғы оң жақтағы «+» ➔ «New repository» батырмасын басыңыз. Репозиторийге атыңызды жазыңыз (мысалы: toi-shaquru) және Public болып тұрғанына көз жеткізіп, «Create repository» басыңыз.

3-қадам: Файлдарды жүктеу (Upload)

Парақшадағы «uploading an existing file» сілтемесін басып, VS Code-та жасаған барлық файлдарыңызды (index.html, CSS, суреттерді) сонда сүйреп әкеліп жүктеңіз және «Commit changes» батырмасын басыңыз.

4-қадам: GitHub Pages қосу

Репозиторийдің Settings ➔ Pages бөліміне өтіңіз. Build and deployment тұсындағы Branch өрісінен «main» (немесе master) таңдап, Save батырмасын басыңыз.

5-қадам: Дайын сілтеме!

1-2 минут күткен соң, сізге https://вашамя.github.io/toi-shaquru сияқты дайын онлайн сілтеме беріледі. Осы сілтемені кез келген адамға жіберсеңіз, олар сайтты смартфонынан оңай аша алады!

📱 Балама жол: Tilda Онлайн Конструкторы

Егер компьютеріңіз жаныңызда болмаса немесе тез арада дайын шаблонмен шақыру сайтыңызды жасағыңыз келсе, **Tilda Publishing** платформасы өте ыңғайлы альтернатива болып табылады.

  • Смартфонмен жұмыс істеу: Tilda-да сайтты тікелей телефон арқылы, арнайы код жазбай-ақ дайын блоктардан кубик сияқты жинауға болады.
  • Дайын Шаблондар: Ішінде той шақыруларына, іс-шараларға арналған сәнді, дайын дизайн үлгілері бар.
  • Жылдам жариялау: «Опубликовать» батырмасын бір басу арқылы дайын сілтеме сәтте шыға келеді.
✨ Қорытынды: ВЕБ-кодтау (VS Code + GitHub) сізге толық эркіндік пен бірегей (уникальный) дизайн жасауға мүмкіндік береді, ал Tilda — телефоннан жылдам веб-шақыру жасап шығуға арналған керемет құрал!
